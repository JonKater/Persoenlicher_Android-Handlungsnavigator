# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/af661587-0195-403a-9603-fc6330c3ad05

## Run Locally

**Prerequisites:**  [Android Studio](https://developer.android.com/studio)


1. Open Android Studio
2. Select **Open** and choose the directory containing this project
3. Allow Android Studio to fix any incompatibilities as it imports the project.
4. Register Android application `com.aistudio.navigator.xptqmz` in Firebase and enable AI Logic with the Gemini Developer API.
5. Configure Firebase App Check with the debug provider for debug builds and Play Integrity for release builds.
6. Download the Firebase configuration as `app/google-services.json` (it is intentionally not committed by this task).
7. Run the app on an emulator or physical device.
